# Laravel-Domänen

- `Market`: Unternehmen, Börsen, Indizes, Kursdaten und Fundamentaldaten
- `ML`: ML-Jobs, Modelle, Trainingsläufe, Predictions und Backtests
- `Subscriptions`: Tarife, Abonnements, Limits und Premium-Rechte
- `Users`: Benutzerprofile, Zustimmungen und Kontoeinstellungen

Die Domänen enthalten später Actions, Data Objects, Enums, Services und Policies. Eloquent-Modelle bleiben zentral in `app/Models`.
